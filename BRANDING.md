## ✅ Recomendaciones para Implementación

### Opción A — WordPress (mismo stack)

- Tema: Hello Elementor + child theme
- Plugin LMS: LearnPress
- Fuentes: Mulish + Poppins
- Paleta: #442e66 + #ffb606

### Opción B — Stack Moderno (Recomendado)

- Framework: Next.js / Astro + TailwindCSS
- CSS en `tailwind.config.js`:

```js
colors: {
  primary: '#442e66',
  accent:  '#ffb606',
}
```

- Fuentes: `next/font/google` (Mulish, Poppins)
- Formularios: React Hook Form + API route
