# Portal del Instituto

Proyecto web para el instituto con noticias y foro de comentarios.

## Objetivos del proyecto

- Crear una página web institucional moderna y responsive
- Implementar sistema de noticias con categorías
- Desarrollar un foro de comentarios simple
- Practicar desarrollo en equipo con Git

## Conceptos aplicados

| Concepto | Clase | Uso en el proyecto |
|----------|-------|-------------------|
| Componentes y props | 18 | Header, Hero, NoticiaCard, etc. |
| useState y eventos | 19 | Estado de noticias, comentarios, formularios |
| Listas con map | 20 | Renderizar noticias y comentarios |
| Render condicional | 20 | Mensajes vacíos, botones habilitados |
| Formularios controlados | 20 | Agregar noticias y comentarios |
| CSS Grid/Flexbox | 17-20 | Layout responsive |

## Flujo de trabajo con Git

1. Clonar el repositorio
2. Crear rama para tu tarea: `git checkout -b tarea/nombre`
3. Hacer cambios y commits atómicos
4. Subir rama: `git push origin tarea/nombre`
5. Crear Pull Request para revisión
6. Merge después de aprobación
